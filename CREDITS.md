# Credits

## XMB wave shader (`xmb/xmb-wave.frag.qsb`)

Shared with [xmb-ps3-theme](https://github.com/luk3h/xmb-ps3-theme), where its source code lives (`shaders/`). The wave has been passed along and improved by several people on Shadertoy:

1. **[int_45h](https://www.shadertoy.com/user/int_45h)**: the original, ["PS3 Menu effect"](https://www.shadertoy.com/view/tXy3DK). int_45h's note:
   > I'm too lazy to copy the MIT license so like just do whatever you want with this shader
   > but like if you can leave a comment or something or hit me up, that'd be dope. thxxx
2. **[llmciv](https://www.shadertoy.com/user/llmciv)**: ["Ps3 XMB 3.0 Background"](https://www.shadertoy.com/view/fcf3Dn). Added dithering, smoothed raymarching, anti-aliasing and the time-of-day colours.
3. **xaot88**: the starfield the sparkles are based on, https://www.shadertoy.com/view/Md2SR3
4. **Dave Hoskins**: the "Hash without Sine" random-number function pattern.
5. xmb-ps3-theme: converted for Qt 6, plus the hourly colour palette.

Thank you all! If you use this, go leave int_45h and llmciv a comment on Shadertoy.

## Menu sounds (`xmb/sounds/`)

Original PS3-*style* sounds generated from plain sine tones for xmb-ps3-theme (see its `sounds/make-sounds.py`). Not recordings of Sony's sounds.

## Category icons (`xmb/assets/categories/`)

Original line drawings made for this project.
